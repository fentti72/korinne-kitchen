ingredients:
  - { amount: 1, item: "banana, mashed" }
  - { amount: 2, unit: tbsp, item: honey }
  - { amount: 0.75, unit: cup, item: milk (or almond milk or another milk alternative) }
  - { amount: 3, unit: tbsp, item: butter or neutral-flavored oil }
  - { amount: 0.5, unit: tsp, item: "vanilla (up to double this, to taste)" }
  - { amount: 1, item: egg }
  - { amount: 1.5, unit: cups, item: "blended flour: any mix of oat flour, rolled oats, whole wheat flour, protein powder, regular or gluten-free flour" }
  - { amount: 0.5, unit: tsp, item: salt }
  - { amount: 0.5, unit: tsp, item: baking soda }
  - { amount: 2, unit: tsp, item: baking powder }
  - { item: blueberries (fresh or frozen) }
steps:
  - Mix the wet ingredients until combined.
  - Add the dry ingredients and mix until half combined.
  - Add the blueberries and fold them in. Do not over mix.
  - Let the batter sit while the pan heats up. Do not stir the batter again.
  - Cook the pancakes just below medium heat on both sides until golden brown.
---
Idea for serving: real maple syrup, peanut butter, and toasted pecans!
