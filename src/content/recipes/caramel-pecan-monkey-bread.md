title: Caramel Pecan Monkey Bread
summary: PLACEHOLDER RECIPE — Korinne will replace this with her own. Pull-apart brioche rolled in cinnamon sugar and baked in a caramel pecan glaze.
servings: 12
prepMinutes: 40
cookMinutes: 35
photo: ../../assets/photos/gallery-monkey-bread.jpg
photoAlt: A ring of monkey bread glazed in caramel and pecans
tags: [baking, breakfast]
ingredients:
  - { amount: 0.75, unit: cup, item: whole milk, warmed }
  - { amount: 2.25, unit: tsp, item: instant yeast }
  - { amount: 0.25, unit: cup, item: granulated sugar }
  - { amount: 2, item: eggs, at room temperature }
  - { amount: 3.5, unit: cups, item: all-purpose flour }
  - { amount: 1, unit: tsp, item: salt }
  - { amount: 6, unit: tbsp, item: unsalted butter, softened }
  - { amount: 1, unit: cup, item: granulated sugar, for coating }
  - { amount: 1, unit: tbsp, item: ground cinnamon }
  - { amount: 0.5, unit: cup, item: unsalted butter, melted }
  - { amount: 0.75, unit: cup, item: packed brown sugar }
  - { amount: 1, unit: cup, item: pecans, chopped }
steps:
  - Mix the milk, yeast, and sugar. Add the eggs, flour, and salt and knead 5 minutes. Knead in the softened butter until smooth.
  - Cover and let rise until doubled, about 1 hour.
  - Grease a bundt pan and scatter half the pecans in the bottom.
  - Pinch the dough into walnut-sized pieces. Dip each in melted butter, then roll in the cinnamon sugar. Layer in the pan.
  - Stir the brown sugar into the remaining melted butter and pour over the dough. Top with the rest of the pecans.
  - Cover and let rise 30 minutes. Bake at 350°F for 30–35 minutes, until deep golden.
  - Cool 5 minutes, then turn out onto a plate while still warm.
---
PLACEHOLDER NOTES. Turn it out while it's warm, or the caramel sets in the pan.
